## Common query parameter

<ParamField query="subscriptionId" type="string">

## Common path parameter

<ParamField path="id" type="string" required>
  ID of the resource instance.
</ParamField>

<ResponseField name="ids" type="string[]">


## CREATEResponseBody

## CREATERequestBody (Enterprise Customer Hosted)

Same as Enterprise BYOA variants except:

- Adds `custom_network_id` (string) at the top level. Custom network to provision the resource in.
- Removes `cloud_provider_account_config_id` and `cloud_provider_native_network_id` from `requestParams`.

Grafana variant adds `custom_network_id` and drops the two BYOA account fields as well.

## CREATERequestBody (Pro Customer Hosted)

Same as Enterprise Customer Hosted CREATE except:

- No `custom_network_id`.
- No `enableEnterpriseModule` in `requestParams`.
- No `maxMemory` in `requestParams`.
