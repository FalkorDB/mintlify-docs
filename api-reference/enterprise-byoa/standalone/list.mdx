Lists the IDs of all Enterprise BYOA Standalone FalkorDB instances in the subscription.

## Authorization

<ParamField header="Authorization" type="string" required>
  Bearer JWT obtained from [Sign in](/api-reference/authentication/signin).
</ParamField>

## Query parameters

<ParamField query="subscriptionId" type="string">
  ID of the subscription. Optional.
</ParamField>

## Response

<ResponseField name="ids" type="string[]">
  IDs of the resource instances.
</ResponseField>

```json 200 OK
{
  "ids": ["instance-abc123", "instance-def456"]
}
```
